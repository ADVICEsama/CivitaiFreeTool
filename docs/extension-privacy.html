CivitaiFreeTool 浏览器扩展隐私政策

更新：2026-11-02

扩展在用户主动操作时读取当前或选中的 Civitai 模型标签页标题和 URL，以提供模型链接批量发送功能；不读取浏览历史数据库。

仅在用户确认发送后，将规范化的模型 URL 发送给本机回环地址 http://127.0.0.1:47531 的 CFT 桌面软件。不会向开发者服务器发送浏览记录，不传输 Cookie、密码或 API Key。桌面软件后续访问 Civitai 的行为独立于扩展。

批次、链接和提交结果保存在浏览器本地，用于状态展示与重复提交保护。用户可在扩展内清除提交记录，或通过浏览器清除扩展数据、卸载扩展。

不出售用户数据；不将数据用于扩展目的之外；不用于信用评估或贷款。没有遥测、广告追踪或开发者数据收集服务器。

支持与反馈：GitHub Issues。请勿在公开反馈中包含密码、API Key 或私人链接。
