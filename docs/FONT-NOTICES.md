# 字体出处与授权记录

## HarmonyOS Sans SC

沿用项目已有字体。正文 400，操作及分区标签 500，主要标题 700；不使用展示字体绘制长正文，不对缺少的字体字重伪造授权。


## 圆构黑体 Alt / Geource Sans Alt

- 作者：howlingFounts，版权方及衍生来源请见完整 OFL 许可。
- 用户指定介绍：https://www.maoken.com/freefonts/27660.html
- 上游与许可：https://github.com/howlingFounts/GeourceSans/
- 许可：SIL Open Font License 1.1，完整许可随包保存在 `web/fonts/GeourceSans-OFL.txt`。
- 来源：用户提供的本地字体目录。内置原始未修改的 CHS Alt Regular / Medium / Bold 三个字重；没有安装到 Windows。
- 用途：终末地亮暗主题默认英文/拉丁与数字。Alt 版采用等宽数字，不将英文字母宣称为等宽。中文默认仍使用 HarmonyOS Sans SC；自定义默认字体及独立字库优先。

## LINE Seed Sans Bold

用户提供的未修改 OTF，PostScript LINESeedSans-Bold，Version 1.002；Dalton Maag Ltd；© LINE 2020。字体内部 name 表确认 SIL OFL 1.1。来源 https://seed.line.me/ ，用途为默认拉丁字母（不接管数字和已自定义字库）。完整许可保存于 web/fonts/LINESeedSans-OFL.txt；仅新增默认字体，不修改系统字体。
