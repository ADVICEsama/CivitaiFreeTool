# 模型加载预算（2026-11-13）

- 禁止让帧数／进度文字更新触发全页按钮、语言、名字测量。
- 瀑布流每帧最多追加 24 卡；列表每帧最多 32 行。只观测新增节点，不每次重复注册全列表。
- 模型封面每批最多 4 张，批间让出主线程；只加载视口附近约 250px。离开范围释放 img.src，瀑布流保存原图宽高比避免塌陷。
- 前端编码封面缓存最多 128 项／估计 32 MiB，后端最多 192 项／32 MiB。不是“全部原图常驻显存”。
- 缩略图边长根据展示宽度、DPR、界面缩放请求，最大 1280；列表不可沿用低分辨率卡片缓存冒充高清。
- 列数计算与 ResizeObserver 必须共用同一函数；隐藏页不是有效宽度依据，显示后重算。
- 600 合成模型压力测试结果见开发环境 .test_tmp/model-stress-metrics.json；无用户模型。中位帧间隔不等同于任何环境的保证帧数。
- 仍需用户在真实模型库、具体显卡／驱动及 WebView2 环境实测，不能仅凭合成测试宣称所有卡死黑屏已修复。
