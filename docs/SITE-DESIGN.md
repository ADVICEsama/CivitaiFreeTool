# 官网分屏与视觉维护

- `docs/index.html` 是 GitHub Pages 首页；应用界面不依赖这些样式。
- 顶部使用项目正式 `assets/wordmark.svg`，亮暗仅改变颜色。箭头使用内联 SVG，不用字体字形塞入裁切容器。
- 七个章节共享固定地图背景：等高线、稀疏网格、几何坐标和锚点。切换章节只平移装饰层，不平移正文，也不复制游戏素材或无关数值。
- 桌面宽度至少 1000px、高度至少 720px 时启用七屏浏览；滚轮一次手势切换一屏，右侧编号导航和 PageUp / PageDown 同样可用。
- 页面内容超出一屏时先正常滚动内容，再进入下一章节；可滚动的内嵌区域不抢滚轮。Ctrl / Command / Alt + 滚轮不接管。
- 手机、低高度窗口保持原生长页滚动。无 JavaScript 仍可阅读所有正文和使用静态下载链接。
- 遵循 reduced-motion，关闭平移过渡和入场动画，翻页改为即时定位。网页只提供简体中文，不冒充完整多语言官网。
- `tests/test_public_home.cjs` 检查明暗主题、320–1440px 布局、键盘预览标签、主题保存和断网下载回退。
- `tests/test_public_home_paging.cjs` 检查四种桌面尺寸的七屏定位、滚轮与键盘、连续滚轮防跨页、手机正常滚动；输出截图供人工检查。
- 仅官网文档调整不重打桌面 EXE、不替换现有 Release 附件。
