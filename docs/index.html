06 / GOOD TO KNOW

开始之前。

它能恢复任何图片的提示词吗？

不能。分析依赖文件中保留的元数据、工作流及支持的节点。被剥离的数据或无法还原的外部动态输出不会被虚构。

扩展会把浏览数据发送到哪里？

仅将你选择的模型链接提交给本机 127.0.0.1:47531，不发送 Cookie、API Key 或网页正文。“已提交”表示软件接收链接，不表示下载已完成。

软件支持哪些语言？

目前有十语言预览，覆盖新手引导和导航；设置及其他页面仍在翻译，不是完整多语言版本。

在哪里反馈问题？

前往 GitHub Issues ↗，附版本、操作步骤与脱敏日志。不要上传 API Key、代理凭据、用户配置或私人路径。
