🧩 Chrome 扩展「一键下载」

📦 下载扩展 zip

浏览 C 站模型页 → 点扩展图标 → 确认小窗 → 一键下载到软件下载管理。

安装步骤：

  • 解压下载的 zip，得到 chrome-extension 文件夹
  • 打开 Chrome，地址栏进入 chrome://extensions/
  • 右上角开启「开发者模式」→「加载已解压的扩展程序」→ 选择该文件夹
  • 工具栏固定图标；需配套 CivitaiFreeTool v2.1.0+
1️⃣ 打开软件→ 2️⃣ 浏览模型页→ 3️⃣ 点图标→ 4️⃣ 确认下载→ 5️⃣ 自动切到下载管理 ✅

❓ 常见问题

软件下载模型很慢 / 连接超时？

C 站被墙需要代理：软件「设置」→ 勾选「启用代理」并确认地址（如 127.0.0.1:7897）。插件小窗报 SSL 错误时同样处理（切换代理节点或稍后重试）。

扩展点图标没反应 / 提示未连接？

确认扩展已加载（chrome://extensions 已启用）且 CivitaiFreeTool 已打开（需 v2.1.0+）；页面必须是 civitai.red / civitai.com 模型详情页。

下载的模型没有触发词 / 缩略图？

使用最新版本（v2.1.5+ 已修复触发词与封面代理问题）；旧模型可在模型管理页重新「校验/补全元数据」或重新下载封面。

浏览器提示扩展不受信任？

未上架 Chrome 应用商店的扩展会显示该提示，属正常现象。扩展源码完全开源可审计，只向本机 127.0.0.1:47531 发送下载请求，可放心使用。
