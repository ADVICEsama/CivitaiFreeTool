🛠️ 安装步骤

  • 解压下载的 zip，得到 chrome-extension 文件夹
  • 打开 Chrome，地址栏进入 chrome://extensions/
  • 右上角打开「开发者模式」
  • 点「加载已解压的扩展程序」，选择 chrome-extension 文件夹
  • 工具栏固定扩展图标（可右键图标 → 固定）

💡 扩展每次更新需重新加载：chrome://extensions/ → 扩展卡片上点「重新加载」

❓ 常见问题

点击图标没有任何反应？

确认扩展已加载成功（chrome://extensions 里已启用）；模型页必须是 civitai.red / civitai.com 的模型详情页。

小窗提示「未连接到 CivitaiFreeTool」？

软件未运行或版本过旧（需 v2.1.0+）。先打开 CivitaiFreeTool，再点扩展图标。

点「开始下载」后提示连接超时/SSL 错误？

C 站被墙时需要代理：软件「设置」页勾选「启用代理」并确认地址（如 127.0.0.1:7897）；若代理节点不稳定，切换节点后重试。

扩展安全吗？

开源（MIT），代码在 chrome-extension/ 目录。扩展只做两件事：读取当前标签页 URL、向本机 127.0.0.1:47531 发送下载请求；桥服务仅监听本机且校验来源，外部网站无法向你的软件提交下载。

浏览器右上角提示扩展不安全？

未上架 Chrome 应用商店的扩展会显示该提示，属正常现象；源码完全开源可审计，可放心使用。
