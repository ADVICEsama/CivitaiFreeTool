# v3.0.25 三种发行形态

- 同一版本提供三种安装形态，文件名后缀标明适配类型：
  - `CivitaiFreeToolWeb-3.0.25-Standalone.exe` —— 纯单文件，双击即用，不需要安装。
  - `CivitaiFreeToolWeb-3.0.25-Setup.exe` —— 安装器，安装到 `%LOCALAPPDATA%\CivitaiFreeTool`，创建开始菜单快捷方式并启动。
  - `CivitaiFreeTool-3.0.25-Portable.zip` —— 免安装，解压后直接运行目录里的 `CivitaiFreeToolWeb.exe`；体积更小、启动更快，但不能单独拷走 exe。
- 三种形态功能完全一致：瀑布流视口外占位、重复扫描不再重建列表、启动期空配置保护均已包含。
- 数据位置仍跟随 exe 所在目录。用免安装版替换旧目录时，配置、任务、历史、缓存自动沿用；安装器装到新目录时是全新配置，需要旧数据请把 `user_config.json`、`download_tasks.json`、`download_history.json`、`model_updates.json` 与缓存目录一起复制过去。
- 未改变模型文件、下载任务或用户设置。语言包仍部分完成，不宣称完整多语言发布。
