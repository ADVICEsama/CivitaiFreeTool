# v3.0.11 下载交互与模型分享

- 下载管理新增全选、反选、取消选择；悬浮窗按钮按实际窗口状态开关。
- 修复队列底栏遮挡、移除无意义的“默认”标签。
- 失败／取消的历史记录新增重试下载，移除无效的本地文件操作；重试按原版本和准确文件身份恢复，缺少身份时明确提示，不替换成其他文件。
- 桌面下载悬浮窗复用主界面字体回退、亮暗主题和共享胶囊按钮；任务区独立滚动、操作区贴底，适配缩放。
- 模型右键新增复制路径、Civitai 链接、缩略图链接和模型分享图片；分享卡包含真实链接二维码，可在设置选择亮暗外观。
- 修复瀑布流尺寸实时刷新、列表视图标签滚轮调节；下载历史缩略图从顶部裁切。
- 禁用桌面悬浮窗后隐藏其相关设置。

## 使用与升级
正常退出旧版后替换 EXE。保留原配置、队列、历史与模型文件。
分享图片需要本机剪贴板支持；失败会给出提示，不宣称已复制。
旧下载历史若既无原任务又无准确版本／文件身份，需从原模型页重新下载。
Chrome 扩展 1.3.1、Firefox 扩展 1.3.2 随包提供，本次未修改扩展。Firefox ZIP 未签名，持久安装需 Mozilla 签名。
十语言仍是预览，其他页面尚未全量翻译；不宣称完整多语言。

自动回归使用隔离数据。浏览器截图验证不等于原生窗口的实际拖动与系统剪贴板粘贴验收。
