## v2.6.14：工作流自适配与多文件版本下载（2026-10-09）

- 修复已分类模型被意外移走：修改全局下载落点仅影响后续下载，不再搬移任何已完成文件；完成回调不再按新全局目录“归位”。恢复的完成任务不再重复执行元数据/封面/移动回调；明确重试仍可正常处理新完成事件。已有模型只有通过明确的移动操作才移动。
- 工作流分析采用“报告式总结 + 自适配工作区”：内容区足够宽时为节点目录 / 只读节点详情 / 引用模型三栏；小窗口直接采用纵向报告，依次为模型依赖、正负提示词、节点目录和详情，不硬挤三栏、不缩小字体。
- 基于内容区逻辑宽度与字号判断，兼容界面缩放和侧栏折叠。窗口调整不重建结果，保留当前节点、搜索和展开状态。上传后收起大拖拽区，结果区域仍可拖入新文件；文件栏可重新选择 / 重新分析。
- 引用模型区显示本地匹配/缺失，路径与 SHA256 前缀默认折叠。提供打开模型和搜索下载；匹配失败独立提示，不误报全部缺失。正负提示词独立阅读/复制，提示词换行和行距优化，保持本地字体及主题。
- 去掉旧版仅显示前 40 个节点、前 20 个模型与提示词截断；保留实际节点 ID、输入关联和输出。API 格式显示真实参数名，UI 格式缺少参数名时按原始顺序显示、不猜测；PNG 同时带 UI / API 数据时按 ID 合并，避免重复。旧匹配响应不会覆盖新结果。
- C站同版本多个模型文件提供多选弹窗：文件名、格式/精度、大小、主文件标记、确认/取消；默认勾选第一个，无人操作 10 秒后默认下载第一个。勾选后停止倒计时；取消不入队。设置 → 下载行为 → 多文件版本下载方式可选择弹窗 / 直接第一个 / 直接全部，仅针对模型变体、不含训练附件。
- 文件选择按独立 downloadUrl 或 fileId 精确入队，保持每个文件的 SHA256 与元数据；同名变体加文件 ID 避免落地冲突。无法明确定位的变体不会冒充主文件下载。
- Chrome / Firefox 扩展 v1.2.0：桥接先确认提交，解析和多选继续在 CFT，避免 6 秒扩展超时与 10 秒选择等待冲突；弹窗及徽标不再把提交误称为已经开始下载。兼容旧同步入队方法，更新模型入口维持原有单文件行为。

验证：355 项既有前端、18 项新增浏览器检查、210 项后端、17 项桥服务；原生 WebView2 隔离验证大窗三栏、小窗报告与指定两个文件入队。使用临时模型 / 虚构 API 数据，无真实大文件下载。已通过登录页面核对示例版本的四个选项及独立 fileId，未点击站点下载、未提取登录信息。

发行附件：EXE、Windows 便携 ZIP、源码 ZIP、Chrome / Firefox 独立 ZIP、SHA256；Firefox ZIP 未签名。用户配置、下载记录和运行缓存不包含在源码 / 发布附件内。
