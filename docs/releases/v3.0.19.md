# v3.0.19 模型详情、对齐与翻译

## 模型信息与图片
- 完整模型信息占满窗口；双击卡片/列表、侧栏左缘展开按钮、反向解析和检查更新的模型信息入口使用同一页面。原侧栏仍用于单击预览。
- 顶栏明确提供收藏、返回紧凑预览（模型管理内）与关闭；底部保留原有操作及文件名翻译。两张主预览与缩略图入口独立；简介和触发词保留原始内容。
- 图片预览序号紧邻左侧标题；百分比按实际字体字形校正垂直中心，操作靠右；放大右侧文字、恢复静态淡等高线。
- 共享胶囊图标修正网格定位继承；文件夹显隐使用实际触发按钮定位，不再锚到右侧「更多」。
- 完整详情按需加载 1024px 本地/在线预览；大图右键新增设为模型封面，写入模型旁 `.cover.png`，不改模型主文件。

## 模型管理
- 顶部快捷筛选改为置顶模型；状态筛选增加无封面，修复状态经扫描桥接丢失和缓存过期问题。
- 顶部二级菜单点击操作后保持展开；同按钮、新菜单或 Escape 关闭。随机模型只从当前筛选结果抽取。
- 分页数量只在翻页开启时显示，使用共享下拉；设置的性能分类保留翻页及每页数量入口。
- 卡片外观编辑使用更大的有效高度，增加针对已选分配对象的随机外观；无选择时禁用。
- 有更新模型增加金色图标和封面细线区分，不新增勾选框。
- 窄窗口双击先选中、再进入完整详情；单击预览延迟 300ms，避免第一次点击布局改变后第二下误触编辑。

## 翻译
- 默认 MyMemory 无 Key 翻译，匿名调用有额度和可用性限制；已有百度凭据继续使用百度，不覆盖用户设置。
- DeepSeek、OpenCode 预设及自定义地址/模型/Key；支持 Chat Completions、Responses、Anthropic Messages、Gemini generateContent 四类协议。不是承诺任意私有协议均可直接调用。
- 翻译仅替换 HTML 文本节点，保留标签、段落、列表、链接、代码和 Markdown 分隔符；原始简介保留，失败不覆盖。
- API Key 只保存在本机配置，不写发布内容或错误提示；拒绝远程明文 HTTP 和带凭据 URL，不跟随带鉴权请求重定向。
- Google / Microsoft 官方翻译需要凭据，不作为免 Key 服务。参考：[Google](https://docs.cloud.google.com/translate/docs/authentication)、[Microsoft](https://learn.microsoft.com/en-us/azure/ai-services/translator/text-translation/reference/authentication)、[MyMemory 额度](https://mymemory.translated.net/doc/usagelimits.php)。

## 验证边界
- 两主题、100/125/150% 百分比字形像素检查；设置各分类、文件夹及侧栏图标几何中心检查。
- 640px 窄窗口、全窗口详情、底部操作可到达、菜单保持展开与互斥、随机筛选范围、分页共享下拉、无封面和置顶筛选回归。
- 本地临时模型的封面写入、扫描缓存及桥接状态回归；不写用户模型目录。
- AI 四种协议使用模拟服务回归，未使用用户 Key 进行付费在线调用；真实服务的配额、网络和账号权限需用户自行配置。
- 十语言仍为部分完成预览，不宣称全软件完整翻译。桌面端原生窗口操作与浏览器模拟验证分别记录。
