## v2.6.5：图片拖动、竖向图片尺寸菜单与最大化残留框修复（2026-10-07）

- 图片大图改为固定滚动视口与独立画布，超大图片两方向均可滚动，滚动条不跟着图片底部移动。按住图片拖动显示位置，支持指针捕获、取消与手势状态，拖完不误触空白关闭。
- 缩放保留查看中心，适合窗口恢复完整图片；滚轮仍缩放图片，Ctrl + 滚轮仍属于全局界面缩放。
- 瀑布流尺寸横向滑条收进瀑布流按钮的竖向二级菜单，悬停/点击/键盘可展开，支持滑条、滚轮、持久化以及 Escape / 点外部收起，高缩放时菜单定位到可见区域。
- 无框窗口常态不再额外添加 Windows THICKFRAME；仅在显式原生调整尺寸时临时启用，结束后撤销。避免无框 WinForms 与非客户区样式混用造成旧窗口尺寸的白色残留矩形。
- 最大化范围在 GETMINMAXINFO 按当前显示器工作区计算，不再覆盖 NCCALCSIZE 的坐标；尺寸改变时更新真实客户端并使旧绘制失效。
- 原有 Mica / Mica Alt 保留，它是不透明的桌面壁纸色调材质，不是透出背后窗口的 Acrylic 毛玻璃。

包含 Windows EXE/便携 ZIP、源码包、Chrome 和 Firefox 扩展及 SHA256。Firefox 扩展仍未签名。
