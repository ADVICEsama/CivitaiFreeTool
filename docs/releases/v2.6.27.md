# CivitaiFreeTool v2.6.27

## 新增
- 终末地独立亮暗布局：顶部主导航、几何图标、等高线与点阵背景、可关闭的鼠标视差、模型详情重点区。
- 液体玻璃亮暗配色；不把普通渐变或系统模糊宣称为真实液体折射。
- Windows 软件窗口模式的桌面下载进度 HUD：不抢焦点、不占任务栏；展开查看任务、暂停全部、继续指定任务、左右贴边收起、缩放、位置记忆。退出软件自动关闭，关 HUD 不停止下载。
- 真实队列字节加权进度；未知大小不显示虚假百分比，未校验完成不提前显示 100%。
- 全主题控件对齐、真实初始化阶段、关于页字体来源。

## 使用与限制
设置 → 外观与布局选择主题；下载管理 → 桌面悬浮窗可随时重新显示 HUD。默认关闭自动常驻，不擅自改变原主题。玻璃 HUD 在 Windows 支持时请求系统 Acrylic，否则回退。不是桌面实时液体折射。浏览器模式不提供原生 HUD。HUD 暂不提供点击穿透；避免隐藏后无法恢复的交互风险。

更新只替换 EXE，保留配置、任务、历史、缓存和模型。浏览器扩展继续使用 1.3.0；Firefox ZIP 未签名，长期安装需要 Mozilla 签名。
