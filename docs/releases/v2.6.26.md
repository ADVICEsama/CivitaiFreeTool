# v2.6.26 · 文件夹显示 / 排除

- 首次默认全部显示；已有用户显隐选择仍保留。
- 点父文件夹，统一显示或排除整棵子树；之前单独设置的子文件夹也同步切换。
- 父文件夹排除后，可单独显示某个子文件夹，不显示父目录直属文件及其它被排除的子目录。
- 父文件夹显示后，排除某个子目录，只排除该子树，父目录直属文件和其它子目录保留。
- **只看某个子目录：先排除父目录，再勾选该子目录。** 再次点父目录显示，会重新勾选全部子目录。
- “隐藏”标签改为“排除”；立即保存、支持键盘，保存失败不改变选择。
- 只修改显示筛选，不移动 / 删除模型。与 A 同前缀的独立目录 AB 不受影响。
