## v2.6.0：原生窗口壳、全窗口 Mica 与图片生成数据（2026-10-07）

- 原生自绘窗口栏替代仅改颜色的系统标题栏，支持拖动、双击最大化、边缘缩放及原生窗口按钮，可在外观设置关闭。
- Mica / Mica Alt 扩展到窗口内容背景；WebView2 在 shown 后透明化，不启用会影响启动时序的提前 Show/Hide 分支。仅支持系统确认成功后启用半透明页面，失败回退不透明底色。
- 模型图片点击放大；保存来源图片、分享链接、到 C站原图页举报入口、复制图片、导出生成数据；完整显示来源提供的正负提示词、资源、参数、本地 PNG / ComfyUI 元数据。缺失数据明确提示，不猜测、不执行节点。
- 详情新增单模型“文件名 → C站名称”预览与改名，不走空筛选时的全库批量逻辑，关联更新历史位置。
- 下载历史信息和双击操作同时定位、滚动并高亮瀑布流/列表中的模型；前端筛选阻挡时自动解除，文件已删除或未扫描时给出原因。
- Release 发布流程改为完整附件校验后才公开，包含 Windows EXE/便携包、Chrome 与 Firefox 扩展、源码包及 SHA256。

### 使用说明

- 保持默认软件窗口与现有下载数据，更新前会备份旧 EXE。
- 全窗口材质入口：设置 → 外观与布局 → 原生标题栏与材质 → Mica / Mica Alt（Windows 11 22H2+）。不支持时回退，不修改系统全局视觉选项。
- 保存来源图片会让你选择位置；图片大图预览最高 4096 px，不自动永久缓存原图。历史只有预览缓存时会说明原图不可用。
- 举报按钮只打开 C站原图页，不直接提交举报。资源列表仅展示来源中存在的数据，缺失时可到原图页查看。
- Firefox ZIP 为未签名扩展，可在 about:debugging 临时加载；长期安装需要 Mozilla 签名，不声称已签名。
