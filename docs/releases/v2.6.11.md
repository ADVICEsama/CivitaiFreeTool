## v2.6.11：三档列表、全功能快捷键与设置防呆（2026-10-08）

- 模型列表提供三档独立大小：完整（当前最大样式）、紧凑（同时去封面/作者，保留本地名）、极简（仅 C站名称与勾选格）。悬停“列表”按钮调节，也可在外观设置中选择；档位保存，缩放/字体/瀑布流大小互不影响。
- 详情“识别模型信息”单击即开始，只处理当前文件，不启动队列中其它待反查模型，不跳页；左下角显示哈希/查询进度，成功更新列表与当前详情。
- 使用资源根据模型 ID、版本 ID、原始模型 URL、AIR 或明确的本地匹配直达页面。仅有版本 ID 使用站点自己的 `/model-versions/{id}` 重定向，不依赖软件先查 API，不再拿 ID 去搜索。打开 C站链接遵循站点设置，默认 `civitai.red`。
- 独立快捷键设置页：默认总开关关闭，方向键 / W-S / J-K 三预设；可搜索应用功能，每项都有“使用”与“点击设键”入口，支持自定义组合键、清除及冲突提示。上下切换模型、F 收藏、R 当前模型反查、空格勾选、Delete 回收站确认、Enter 大图为常用预设。
- 快捷键只作用于本软件和对应页面；文本输入、组合输入、确认弹窗与选择菜单中不触发。无全局键盘钩子；删除沿用回收站确认，不做永久删除。
- 新手教程先引导到 `civitai.red/user/account` 申请并填写 API Key，空值不能继续/跳过，先保存 Key 再进入原有页面介绍。已配置 Key 可直接继续；此步骤检查填写和保存，不假装验证远端 Key 权限。
- 下载任务增加勾选框/表头全选，单击选中，刷新保留选择；按任务 ID 操作，避免同名任务互相影响。新增全部暂停、全部移除确认，明确全部移入下载历史仅处理已结束任务，不删除模型文件。
- 设置未保存离页/关窗时提供保存并离开、放弃修改、继续编辑；保存失败保留输入并留在设置页，已即时保存的选项不重复提示。原生关闭事件也拦截未保存修改；浏览器刷新/关页提供未保存提醒。

更新说明和 README 新增三档列表的虚构示例截图。所有自动回归使用模拟 API/临时模型；未用用户 Key 做在线反查，也不上传用户配置、模型和缓存。
