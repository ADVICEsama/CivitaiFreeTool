## v3.0.7 - 2026-10-27
- 重点修复拖动整个窗口的链路：自定义拖动区由逐次 JS→Python move 请求改为一次异步入队的 Windows 原生系统拖动，避免鼠标移动消息积压；保留系统 Snap/DPI 行为。迟到请求在鼠标已松开时不启动拖动。
- 原生移动/缩放开始与结束只发送两次异步状态通知，不在 WinForms 消息循环里同步等待 JavaScript。
- 新增“拖动/缩放窗口时暂缓背景绘制（松手恢复）”，暂停仅发生在拖动期间，可关闭；不改变下载任务，不强制关闭 GPU 加速。
- 新增极致、高、均衡、低四个性能档位和独立界面动画开关；首次选择采用关于页式横幅、角色、三色顶线、入场动画和统一胶囊按钮。设置新增独立【性能】分类，集中管理帧率、动画、GPU 兼容性和缓存。首次升级可选择，也可保留旧设置；成功保存后不反复弹出，设置中随时可改。
- 极致背景跟随屏幕刷新率（0，不锁 60），高为 60 FPS，均衡为 30 FPS，低停止界面动画和连续背景绘制；不停止视频或下载。
- 隐藏的 WebGL 背景不再维持空转回调；屏外辅助等高线暂停。地图按空间批次剔除屏外线段，保留原始几何，隔离像素 A/B 无差异。
- 验证：435 项后端测试，原生壳编译和隐藏窗口进出移动消息测试；亮暗主题档位持久化/保存失败回退、拖动暂停恢复、静态停绘和页面回归通过。真实鼠标拖动手感仍需用户在目标硬件上验收，不将测试回调数等同于实际 FPS 提升。
