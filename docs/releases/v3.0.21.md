# v3.0.21 独立查重页面

- 查重入口只打开独立二级页面，不立即启动任务。先显示上次完成的结果和时间；确认后只检查进入页面时选中的模型。
- 未选中模型时开始按钮禁用，不会退回全库扫描。哈希重复和同模型多版本都限制在选中范围。
- 结果保存到本地 dedupe_result.json，重启后仍能查看；损坏或缺失缓存安全回到空状态。不会修改模型文件。
- 查重采用满宽三色线、等高线横带，放大可滚动结果区；选择操作置于上方，关闭和移入回收站居中置底。回收站操作仍须二次确认。
- 外观页高度随内容收紧，去掉外壳网格底部额外空白，保留宽屏可用宽度。
- 隔离浏览器验证亮暗主题、2560/1440/640 宽度及 125% 缩放；验证进入不启动、确认后启动、选中范围与缓存恢复。后端新增范围隔离和并发保护测试。
- 语言包仍为部分完成；没有宣称全量多语言完成。实际桌面用户库仍需实测。
