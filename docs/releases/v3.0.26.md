# v3.0.26 扫描后自动加载全部封面、首次启动自动扫描

- 点「扫描模型」或「刷新」后，自动按批把**当前显隐设置下全部模型**的封面取回来放进缓存，不再需要滚动到才能看到。状态栏显示 `正在加载封面 x / y`，完成后显示 `封面加载完成：x / y`。
- 封面缓存上限从 128 条 / 32 MB 提高到 1024 条 / 96 MB，整库封面（数百个模型）可以常驻，滚动时不再反复加载。
- 首次打开（本地还没有扫描结果）时自动扫描一次，进度写在左下角状态栏；已有扫描结果则直接补封面，不重复扫盘。
- 修复瀑布流里大部分卡片只显示空底色、没有封面的问题：封面管线原本只为视口 ±250 px 内的卡片取图，视口外一律留空；现在扫描后会补齐全部。
- 封面预取与缓存按性能档位分级：极致 批 32 / 间隔 8 ms / 缓存 1536 条 128 MB；高 批 24 / 12 ms / 1024 条 96 MB；均衡 批 16 / 24 ms / 512 条 48 MB；低 不预取、仅按需加载、128 条 32 MB。切换档位立即生效。
- 瀑布流的视口保留缓冲也随档位变化（极致 0.60 屏 → 低 0.35 屏），低档渲染更少。
- 封面缩略图增加**磁盘缓存**：320px 缩略图写入 detail_thumb_cache\cov-320-*.jpg，整库约 8.9 MB；重启软件后直接读盘，不再重新解码原图（冷启动 75 秒 → 热启动约 19 秒）。
- 增加**模型→封面路径索引** cover_index.json（约 88 KB），避免每次取封面都做 15 次文件探测；后端一次返回 362 张封面从 30 秒降到约 1 秒。
- 发行文件名统一为产品名：`CivitaiFreeTool-<版本>-Standalone.exe` / `-Setup.exe` / `-Portable.zip`。
- 没有改变模型文件、下载任务或用户设置。语言包仍部分完成，不宣称完整多语言发布。
