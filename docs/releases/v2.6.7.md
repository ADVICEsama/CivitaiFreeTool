## v2.6.7：连续缩放、本地原图缓存与收藏工作台（2026-10-07）

- 大图滚轮根据实际滚动增量连续缩放，使用时间插值平滑过渡，缩放范围 5%–3200%（相对适合窗口）；保留鼠标附近缩放中心及按住图片拖动。
- 默认缓存已查看的原图、预览和来源生成数据，重新打开优先本地读取；不预下载未查看图片，不伪造缺失参数。独立开关、64–8192 MB 容量和清理入口，默认 1024 MB；软件数据迁移包含缓存。
- 拖尾/点击与背景动画帧率独立设置：15–360，0 跟随屏幕刷新。性能档只控制粒子与像素预算，实际帧率仍取决于硬件、屏幕及 WebView。
- 特效改为覆盖存活粒子的局部画布，缓存主题色；大图保留半透明遮罩但移除整屏背景模糊，打开时暂停背后的氛围动画，降低软件渲染负担。
- 图片使用资源支持打开 C站：模型 ID 直达、版本 ID 查询模型 ID、本地文件名精确匹配；无法确认 ID 时明确打开名称搜索，不猜测模型链接。
- 模型右键与详情右上角提供收藏置顶星标，收藏始终排在普通模型前；改名与移动跟随文件路径更新。
- 模型管理标题右侧可固定顶部菜单，瀑布流与列表仅滚动下方模型区；保存状态。
- 新手引导压缩为三步，主题化视觉欢迎、目录和可选 Key；跳过后不因未填 Key 每次启动重开。

Windows 默认仍为软件窗口、保留浏览器兜底。发行包含 EXE、便携 ZIP、源码、Chrome / Firefox 扩展与 SHA256；Firefox 扩展未签名。运行配置、Key、真实模型与原图缓存不进入发行包。
