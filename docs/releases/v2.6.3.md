## v2.6.3：菜单拖窗修复与无底色窗口按钮（2026-10-07）

- 关闭 pywebview 无框窗口默认的整窗 easy_drag；只允许页面标题/侧栏名称直接拖动，避免设置的下拉菜单、字体菜单和其他输入控件被拖窗监听抢走。
- 移除覆盖 WebView 的 WinForms 角落面板；右上角三个窗口按钮改为网页主题渲染，默认透明无底色，颜色、圆角、悬停和焦点跟随现有 UI，不添加顶栏或重复 Logo。
- 最小化、最大化/还原、关闭通过受限 API 排队到原生 UI 线程；关闭仍遵循保存/最小化设置，边缘仍支持缩放。
- 降低 Mica 模式下面板和列表行的底色遮盖，隐藏不透明氛围画布；材质来自原生 DWM，而不是网页渐变假冒。
- 外观状态增加系统透明开关、高对比度和激活状态诊断。Mica 是桌面壁纸色调，不是透视背后窗口的实时毛玻璃；失焦、系统关闭透明等情况下 Windows 会回退纯色，不强改系统设置。

包含 Windows EXE/便携 ZIP、源码包、Chrome 和 Firefox 扩展及 SHA256。Firefox 扩展仍未签名。
