- 模型管理瀑布流把视口上下各一屏之外卡片的**内容**移到离屏片段保存，盒子高度按实测值钉住，回来时原样塞回。列高、卡片位置与滚动条长度都不变。
- 大幅降低"滚轮一下子甩到中段或尾部"的卡顿：同一台机器、同一份 362 个模型，最慢单帧从 422–894 ms 降到 74–156 ms。

- 判定一律以实时矩形为准，索引只用于缩小检查范围；封面陆续加载改变布局后仍能正确恢复。
