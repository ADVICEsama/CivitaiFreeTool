## v2.6.17：批量选择安全、改名移动与下载历史修复（2026-10-09）

- 修复筛选外隐藏模型仍被勾选并参与批量移动：底模、类型、作者、状态、目录、关键词改变时，清除不可见选择；所有批量入口再次限制在当前显示行。不会恢复或重新整理用户已经移回的模型。
- 后端明确传入空列表 / 未匹配路径时，不再退回“全部模型”；拒绝重叠的后台改名操作。
- 修复批量改名还在后台执行时就提前扫描，导致列表缓存旧文件名、反向解析 WinError 2。改名完成后才刷新；已知改名/移动立即同步模型行、反向解析队列、下载历史、收藏与更新缓存；仅跟随已记录的真实改名，不按相似名称猜文件。
- 内部扫描和反向解析路径规范化；报错中的两个反斜杠是转义显示，不是根因。文件确实被外部改名/删除时，显示明确提示，不继续对失效路径做哈希或联网查询。
- C站名、中文名和自定义改名统一处理全部已识别附属文件及 .images 图片文件夹。同名模型 / 侧车 / 图片目录冲突时不执行；途中失败尽量整体回退，回退失败明确报告。后续移动携带同名图片目录，不恢复用户已删除的旧目录。
- 右键一级菜单增加“移动到…文件夹”，仅操作右键当前模型，不夹带其它勾选；统一使用文件夹选择器、确认和带冲突检查的移动流程。
- 搜索框尾部内嵌 ×，只清搜索；“清除勾选”独立保留。整理、移动、扫描、选择等按钮和菜单补充用途悬浮说明。“整理模型”是按规则移动，不是刷新。
- 更新管理自动过滤文件已不存在的旧缓存路径，改名/移动同步更新缓存键，防止旧 284 条加新 252 条显示成 536；手动“同步本地模型”仍保留。不删除模型文件。
- 下载管理新增“移除已完成”：只收起完成项，下载历史和模型文件保留，不影响失败、取消、暂停、排队或下载中的任务。
- 下载表格大窗吸收剩余宽度，消除右侧大片空白和不必要的横向滚动条；窄窗仍可横向滚动，列宽可拖动保存。勾选框与点阵排序手柄放大并垂直居中。
- 下载封面悬浮窗不再只放大小图：单独读取 1024px 高质量在线预览、已缓存原图或本地高清封面；请求去重，内存缓存上限约 32 MB，不在悬停时自动下载完整原图。不存在高清来源时不能凭空增加细节。
- 正在下载 / 排队 / 重试 / 暂停的同一任务不作为失败历史展示；真实终态仍记录。历史轮询只在内容变化时重建列表，复用封面数据；封面实际变化按修订号更新，避免持续读取与闪烁。

验证：264 项后端；355 项既有前端、18 项工作流、27 项下载、15 项目录类型筛选、18 项操作安全界面检查（前端共 433 项）；17 项桥服务、10 项来源检查。隔离 WebView2 验证隐藏选择清除、图片目录改名、反查路径同步及旧更新过滤，原生异常为 0。全部自动测试使用临时文件和模拟桥接，不搬动用户模型、不重跑用户真实反查。
