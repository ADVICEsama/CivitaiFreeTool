# v3.0.20 图片缓存与界面修复

## 图片与模型信息
- 批量下载封面结束后清除对应模型的前端图片缓存、缺图缓存及尺寸缓存，再刷新扫描；图片加载失败不再保留坏图片标记。
- 大图右上角三点与图片右键共用操作菜单；支持键盘选择、Escape 和关闭清理，防止菜单残留到其他页面。
- 大图遮罩使用相同半透明配色，从大模型页打开也不改为实色。
- 大模型信息页使用单图片舞台，移除容易空白的第二张加载区；增加上一张/下一张图片和上一项/下一项筛选模型入口。
- 顶栏只保留 X 关闭；长标题限制两行，保留收藏操作。左右留出模型切换空间，底部操作居中，滚动后仍有等高线。
- 侧栏展开改为向左箭头，留独立边缘空间，不覆盖触发词。
- 已缓存原图沿用既有本地/内存复用路径，不再另发第二套高清预览请求。

## 排版与说明
- 查重的选择类操作采用两列分组，关闭和移入回收站独立居中，窄窗不挤掉文字。
- 模型卡片外观页适度加宽并缩减高度；等高线按素材原始比例重复，修复透明空带。
- 设置打开日志按钮靠内容右缘；共享语言入口显示“简体中文（Simplified Chinese）”。
- 工作流引用模型旁增加匹配说明：当前本地按文件名查找，缺失时按名称搜索 C站，不代表已通过哈希校验，需核对版本和底模。不会编造缺失文件的哈希。

## 性能与验证边界
- 原生 base64 转换可用时优先使用；旧 WebView 分片转换并让出主线程，不降低动画质量。不再因其他页面滚动请求工作流重绘，封面批次之间让出绘制机会。
- 隔离 Chromium 合成 8 MB 数据转换测试：旧字节循环约 44 ms，原生转换约 8 ms。这不是整页 FPS 或所有设备的提升保证。
- 后端 516 项回归通过；本地浏览器验证亮暗主题、窄窗口、80–125% 缩放、图片缓存复用、菜单、封面缓存失效、反复大小窗切换、查重分组及设置按钮位置。
- 语言包依旧部分完成；用户实际模型库、实际桌面运行的视觉与性能仍需实测。
