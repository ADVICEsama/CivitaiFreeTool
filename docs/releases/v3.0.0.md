# CivitaiFreeTool 3.0.0

## 工作流分析
- 3D 建筑沙盘与 2D 平面图，保留实际节点、端口与连接；连线光点仅是方向提示，不代表任务正在执行。
- 默认左键拖动，空格 + 左键旋转。顶部可选择左键默认拖动 / 旋转 / 选择；滚轮缩放。
- 2D 中拖动卡片可调整节点位置，连线实时跟随。位置仅保留于当前文件会话，重新解析即重置，不写入图片、JSON 或模型文件。
- 名称完整换行，2D 不因卡片重叠或部分裁切而整卡隐藏；卡片与柱体扩大悬停范围，高亮相关真实连线。
- 2D 平面图使用细格子背景，画布外恢复未放大的七节点等高线地图；每张节点卡片使用独立、靠右、静止且渐隐衔接的等高线纹理。
- 卡片背景等高线；亮暗配色分别优化。光点尊重系统减少动画设置。
- 远景分级简化、几何缓存、可见区域剔除，镜头移动期间仅简化建筑栅格，停止后恢复清晰。

- 两侧提示词和节点详情可拖动、拉大；图钉可固定当前节点详情，继续查看其他节点，固定窗口支持单独关闭。

## 工作台
终末地亮/暗主题统一导航、设置、模型管理、下载管理、检查更新、反向解析与关于页。保留现有后端下载、匹配及隐私行为；预览不代表真实下载或执行工作流。

## 交付
Windows EXE，版本号 3.0.0。不打包用户配置、令牌、下载队列或历史数据。运行需要 Windows WebView2 Runtime。
