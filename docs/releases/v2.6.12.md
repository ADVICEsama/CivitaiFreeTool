## v2.6.12：快捷键对齐、极简列表信息与状态胶囊（2026-10-08）

- 快捷键改为功能名称 + 绑定按钮；删除“使用”按钮和多预设选择。只有一套常规初始值，用户可自由修改，改动后绑定按钮左侧出现单项“重置”。按钮按列对齐，验证了标准/大字号、窄窗和全局缩放。
- 点击绑定按钮或聚焦后按 Enter 开始；录入一次后立即退出。Esc 或退格键清除绑定，Tab / 失焦取消录入；重置只恢复当前项，初始值为空的项重置为未绑定。旧 W/S、J/K 导航键迁移为自定义值，不自动开启。仅聚焦不持续拦截按键。
- 图片大图的左右切换也遵循快捷键总开关；关闭时不拦截应用命令。按钮、文字输入以及 Escape/Tab 等对话框基础操作仍保留。
- 列宽改为勾选小列、名称按档位定宽、路径弹性，修复勾选和名称各占半行的问题。单元格横向间距收紧；忽略旧版异常勾选列宽，保留其余列手动宽度，文字悬停查看全文。
- 极简列表只精简模型信息单元格中的封面、作者、本地文件名。类型、基础模型、版本、更新、大小、下载时间、路径等信息列仍保留，沿用用户的列显隐与宽度设置；窄窗可横向滚动。
- 左下角状态保持不变，同时在画面底部中心显示主题适配圆胶囊，约 2.6 秒后淡出，不挡鼠标，不遮住设置页底部按钮。重复轮询不续提示寿命，新提示不会被旧淡出计时器误隐藏。

验证：模拟 API 界面回归、后端回归及隔离 WebView2 原生窗口检查，不使用用户 Key 发起联网模型请求。

关于 STranslate 的 Shift+Alt+S：已验证 CFT 总开关关闭时自身页面监听不阻止该组合键；未操作或改写 STranslate 配置，尚未确认用户实际全局热键恢复。STranslate 官方代码包含“全屏时忽略快捷键”判断，无边框最大化可能触发此条件，可用还原窗口与其对应设置进一步区分原因，不把推测当成已修复。

发行附件：EXE、Windows 便携包、源码 ZIP、Chrome / Firefox 独立 ZIP、SHA256；Firefox ZIP 未签名。
