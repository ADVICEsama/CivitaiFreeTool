# v3.0.17 模型管理、封面与界面修复

- 移除固定的瀑布流列容器，改为 CSS 响应式列与卡片高度跨度；窗口增宽不再依赖旧列数记录或搬运列容器。
- 三视图复用已建立的卡片／列表节点，返回模型页不重建；筛选、扫描、排序、模型内容或外观改变时按需失效。离开页面保留已解码可见封面，避免返回时重复解码。
- 搜索移到顶部指定空位；全选、反选、清除直接可见；底部筛选只向右展开四项枚举并常驻，统一控件高度。
- 修复代理状态同步覆盖二级菜单标签的根因，保留图文结构与居中；更多去除重复清理入口，信息菜单去除与主栏重复的封面下载入口。
- 分享附加小图不再联网等待，只用当前已加载／本地缓存小图；模型详情增加有界缓存（最多12项），根据元数据／图片文件变更失效。超长文字裁切改二分测量。
- 列表选中后所有信息列文字变金色；触发词黄色编号改深色数字。

## 验证与限制
- 后端502项回归；两主题、125%缩放、358卡片反复窄宽变化、真实位置不重叠、视图节点复用、菜单居中、触发词对比度、整行金字检查。
- 独立真实 WebView2 窗口示例，358卡片加载时从约942px增至2552px，可见列2→9；不等同于用户完整模型库最终验收。
- 358合成模型首次方格约1787ms，缓存返回约193ms，页面返回约145ms（本机隔离示例，非用户实机保证，不代表整体帧率已提升）。
- 不改动用户配置、队列、模型；不覆盖运行中的程序。GitHub 发布前核对附件哈希；桌面发布目录保留旧版本。多语言仍为部分完成预览。

## 本次追加修复
- 移除重复的「下载目标文件夹（预设）」设置项；保留「目录与账号 → 下载目录」。未擅自改写用户已保存的目录或批量下载的临时目标。
- 下载封面默认开启。下载完成或反查成功时，缺封面则保存真实 PNG 到模型文件旁，优先复用缓存；已有封面不覆盖。
- 分享附图优先使用已加载/本地小图，缺失的并行补 160px 缩略图，最多等待约2.4秒，不下载附图原图；卡片最多展示四张附图。二维码上方增加“下载该模型”，没有附图时网址底边与 Logo、二维码齐平。
- 新手引导扩大宽度与可用高度，短步骤不再把内容压成窄横带；小窗仍可滚动，底部操作可达。
- 长名称右键菜单限制宽度、标题省略，缩放后限制在窗口内并置于侧栏上层；修复卡片名称首行缩进。
- 「有更新」筛选开启后保持金色和下划线，辅助操作按钮图标按按钮本身垂直居中。
- 启动时检测 Windows 系统中已配置且可连接的 HTTP(S) 代理并启用。不扫描端口，不猜测仅TUN模式的VPN，不关闭证书校验；未发现可用代理时保留原设置。
- 关于页增加软件官网；官网、仓库、上报问题均打开并复制链接。更新检测在 GitHub API 失败时回退官方稳定版页面，反馈移到按钮上方。官网版本获取失败时不再显示过时的3.0.9。
- 反向解析背景柱移到左下留白，避开右侧空状态文字。
