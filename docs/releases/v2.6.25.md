# v2.6.25 · 批量标签页、API Key 指引与反查列表

## Chrome / Firefox 扩展 1.3.0
- 新增“批量标签页”，所有窗口 / 当前窗口、模型名搜索、勾选和全选；一次发送到本机 CFT。
- 重复标签按模型/版本/文件 ID 合并，保留不同版本和文件；不读取网页内容，不传 Cookie / Key / 无关标签。
- 后台顺序提交，关闭小窗继续；显示每条提交结果，未获确认不自动重试。需要重复发送时显式清除扩展提交记录，不改 CFT 任务。
- Chrome/Edge 加载已解压扩展后请点重新加载；Firefox ZIP 未签名，临时加载，永久安装需 Mozilla 签名。

## API Key 与反查教程
- 空 API Key 时锁住批量下载、下载管理、检查更新、反向解析；半透明遮罩直达设置，默认申请入口 civitai.red。
- 后端拒绝无 Key 新增在线操作，快捷键 / 扩展也不能绕过。不会删除本地模型、任务或历史，不强停已有下载。
- 五步教程：模型管理 → 全选 → 信息处理 → 识别模型信息 → 开始反查；教程不替用户开始操作。

## 列表与工作流
- 反查行勾选、仅失败筛选、反查选中、移除选中；筛选范围外不操作，移除不删除模型，运行中记录保留。
- 反查和下载历史表格自适应铺满窗口；列宽仍可拖动。
- 修复 LoRA Manager `loras.__value__` 引用遗漏，支持 JSON / UI 栈与无后缀模型名。停用模型另列，API 记录优先于旧 UI，不把文字注释当模型；匹配所有已配置模型目录。

## 数据与校验
- 更新只替换程序和扩展，不搬移模型、不清缓存和历史。源码/ZIP 不包含用户配置、Key、任务或用户图片。
- 原生界面、后台与浏览器状态均以实际校验结果为准；提交成功不代表模型解析或下载成功，多文件选择仍在软件内完成。
