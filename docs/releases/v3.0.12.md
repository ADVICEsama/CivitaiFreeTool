# v3.0.12 模型加载与显示修复

- 模型列表与瀑布流分帧追加卡片；过滤无关的全局 DOM 装饰触发，避免帧数和下载文字刷新引发整页重复处理。
- 封面按视口加载，远离视口释放图片源并保留布局比例；前端和后端缓存设定容量上限，请求最多每批四张。
- 列表背景按实际显示尺寸请求清晰封面，不再放大小缩略图；保留居中裁切。
- 瀑布流按工作区宽度统一计算列数，切回页面重新校准，修复隐藏页计算导致的偶发少列。
- 下载历史整组文件文字上下居中，表头不覆盖批次；历史与队列封面均上下居中。
- 桌面悬浮窗入口移到下载操作区；小窗三按钮占用独立空间，不覆盖速度和百分比。
- 修复详情封面右键菜单层级；分享图片采用与主界面一致的默认分文字字体，减小简介字号、垂直居中标签、底部链接与二维码齐平。

## 验证范围
600 个合成模型的浏览器压力测试已检查视口加载、列数恢复、缓存和批量限制；测试帧间隔不代表所有电脑或真实大图都能恒定满帧，也不承诺彻底消除黑屏。源图尺寸、显卡驱动和 WebView2 状态仍可能影响实际性能。
已进行两主题截图、图片右键、下载历史与悬浮窗布局检查。
