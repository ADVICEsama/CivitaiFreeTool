## v2.6.16：独立文件夹选择与模型类型筛选（2026-10-09）

- 文件夹显隐使用显式目录选择，子目录选择优先：隐藏 A 时仍可勾选 A/B；勾选 A、取消 B 则排除 B 及其子树，B 下更深的目录也可另行勾选。不移动、改名或删除模型。
- 设置 → 外观与布局增加“勾选文件夹包含子目录”，默认开启；关闭后只显示被勾选文件夹直属的模型，不自动包含未选子目录。保存后刷新模型列表，无需重启。
- 旧版隐藏目录设置保留并迁移，无需重新选一次。根目录直属模型单独控制；全部显示/隐藏覆盖所有层级。选择状态保存并在重开后恢复，保存失败不改变选择；支持键盘空格/Enter。
- 显隐菜单采用勾选框并显示当前状态、规则说明。同步前端配置，避免之后保存其它设置把刚选的显隐状态覆盖。
- 模型管理新增“全部类型”筛选：大模型（Checkpoint / UNet）、LoRA / LyCORIS、VAE、ControlNet、Embedding、Hypernetwork、放大模型、文本编码器、Motion Module、其它、未识别。与底模、作者、状态、关键词叠加，列表/瀑布流共用。
- 类型优先读取已有模型元数据；缺失时仅根据标准目录名称判断，不按文件大小、文件名或扩展名猜测。无法判断时保留“未识别类型”，不写回或篡改模型元数据。
- README 补充两项功能与虚构数据演示截图。

验证：249 项后端；355 项既有前端、18 项工作流、27 项下载、15 项新筛选界面检查（前端共 415 项）；17 项桥服务、10 项来源检查。隔离 WebView2 验证父目录隐藏/子目录显示和类型筛选，原生异常为 0。测试只使用临时文件与虚构数据，不操作用户模型，不发起真实大文件下载。
