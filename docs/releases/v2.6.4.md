## v2.6.4：无色边框、贴角窗口按钮与图片右键（2026-10-07）

- WebView 按真实 GetClientRect 铺满，不再留 4px 原生底色边；内置窗口模式关闭 Windows 默认色边框，保留原生圆角与缩放。
- 窗口三个按钮贴齐右上角顶部；增加横向透明拖动区域，页面标题、侧栏名称、图片工具栏空白也可拖动，输入控件不参与拖窗。双击拖动区可最大化/还原。
- 不靠可见边框调整大小：八个透明边缘操作通过固定方向 API 交给系统缩放，最大化时隐藏。
- 图片两侧黑色空白可退出大图；点击图片/翻页/缩放/生成数据区不误关。右键提供复制图片、保存、原图页和提示词/全部生成数据复制，Escape 优先关闭右键菜单。
- 复制图片使用真正的 Windows CF_DIB，并保留网页 PNG ClipboardItem 兜底；不把 JPEG blob 错标为 PNG。复制当前加载预览，保存来源图片仍使用原来的保存对话框。
- 删除举报入口；修正更多图片操作图标水平和垂直居中。
- 模型列表/瀑布流共用右键菜单：默认四个常用动作，复制、改名与整理、元数据与更新三个折叠分组；原有十三项保留，新增查看模型信息。分组支持键盘操作和高缩放边缘限制，回收站操作仍确认。

包含 Windows EXE/便携 ZIP、源码包、Chrome 和 Firefox 扩展及 SHA256。Firefox 扩展仍未签名。
