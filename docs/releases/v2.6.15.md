## v2.6.15：下载操作、命名、列宽与工作流完整模式（2026-10-09）

- 下载任务支持手柄拖动排序，前面的等待任务优先，当前下载不中断；队列顺序保存并恢复。同时下载数量放到“下载行为”，1–32 个；降低数量只限制后续启动。
- 修复网络重试恢复后仍显示“等待中”：每次真实重试进入“下载中”，重试退避单独显示“等待重试”并清零速度；重试等待也可暂停。
- 下载管理新增“开始 / 继续选中”：只处理勾选任务，不把空选择当全部；保留全部开始、全部暂停和单项暂停。新任务 ID 增加随机唯一标记，避免短时间同名任务撞 ID 后误操作其它任务。
- 任务入队前优先取得 512px 封面缩略图，等待最多 3 秒，失败不阻塞模型下载；缓存写在软件数据目录，不提前在模型分类目录创建封面。旧未完成任务通过最多两个后台封面线程补缓存，避免反复请求。队列缩略图按任务 ID，不按同名文件串图。
- 下载管理 / 历史、模型更新管理、反向解析、工作流图片和引用模型支持鼠标旁的悬浮大封面；有本地路径时读取更清晰的 512px 缩略图，不加载原图。浮窗不截获鼠标，避免越界；离开、滚动、点击时收起。
- 下载任务、历史、更新管理和反向解析表格均可拖动表头右缘调整列宽，双击恢复该列默认，并独立记住宽度；窄窗横向滚动。模型列表既有拖动修正 CSS 缩放下的宽度跳变。勾选 / 小封面列仍保持窄列。
- 模型更新管理新增“同步本地模型”：重新扫描本地模型，清理已删除或不在当前模型库的旧更新缓存，刷新两页列表；不访问 C站，不移动 / 删除模型。目录离线、扫描失败或缓存保存失败时保留旧更新记录；同步和在线更新检查互斥。
- 设置 → 下载行为提供原文件名 / C站模型名 / 中文模型名；中文仅翻译名称，不翻译版本号，服务不可用时保留 C站名。旧中文命名设置迁移为新选项，多文件变体保留文件身份避免覆盖。
- “命名附加模型版本号”默认关闭。开启后使用“模型名字-原始版本号.后缀”，C站名 / 中文名改名、预览和手动编辑共用该策略；编辑框沿用下载命名默认设置。缺少版本信息不编造；原文件名自身带的版本文字不会被自动删除。
- 工作流分析新增 Forge / A1111 PNG parameters 读取：提示词、负面提示词、生成参数、明确记录的模型与 LoRA 引用。仅本地唯一名称匹配，不把未匹配名称猜成 C站模型链接；压缩的 ComfyUI PNG 元数据也可读取。
- 右上角“精简 / 完整”切换并记住视图：完整增加只读节点画布，使用实际节点 ID / 保存位置 / 输入连接画线，支持拖动平移、滚轮缩放、适合窗口和点击查看参数。没有连接数据时不造连线；Forge 没有节点图时明确说明，仅展示其已有参数。
- 工作流引用模型展示现有本地封面；不存在封面不会伪造或猜测在线模型。画布最多绘制前 300 个节点以保护性能，并明确提示；节点目录和解析数据仍保留全部。
- 延续 v2.6.14 的分类保护：全局目标不移动已完成模型，恢复的完成任务不重复触发元数据 / 移动回调。

验证：355 项既有前端、18 项工作流/多文件、27 项新增界面检查，240 项后端、17 项桥服务及 10 项来源检查；隔离 WebView2 验证自适配、真实节点连线与各页列宽入口。测试使用临时模型、虚构元数据和模拟桥接，不下载真实大文件、不操作用户模型目录。

Forge 元数据格式参考官方源码：[images.py](https://github.com/lllyasviel/stable-diffusion-webui-forge/blob/main/modules/images.py) 与 [infotext_utils.py](https://github.com/lllyasviel/stable-diffusion-webui-forge/blob/main/modules/infotext_utils.py)。

发行附件：EXE、Windows 便携 ZIP、源码 ZIP、Chrome / Firefox 独立 ZIP、SHA256。扩展保持 v1.2.0，Firefox ZIP 未签名。配置、下载任务、运行缓存与恢复备份不包含在源码及发布包里。
