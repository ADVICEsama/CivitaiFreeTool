# CFT 界面与语言规范

> 维护日期：2026-11-08。本文是后续开发的统一验收标准，不表示旧页面已经全部达标。
> 优先顺序：用户最新明确要求 > 本规范 > 页面历史实现。已有 bug 不是设计规范。

## 1. 设计定位

**一张连续地图上的模型工作台，而不是七个互不相关的网站。**

- 视觉语言：终末地式工业界面；等高线、地图锚点、直角几何、克制的斜线纹理、鲜黄强调。
- 只保留终末地亮／暗两套主题。明暗改变背景与对比关系，不改变布局和操作含义。
- 左侧导航与右侧内容浑然一体：不加生硬分割边框，不叠一层不透明大底板遮住地图。
- 信息优先于装饰。模型名称、状态和操作必须一眼可读；纹理与发光不能压住文字。
- 不复制游戏中与软件无关的资源数值、任务文案或无意义按钮。装饰用英文也不能冒充功能。

## 2. 颜色与层级

- 强调色沿用 `--ef-yellow`，不在新页面另造一个“差不多的黄”。
- 次操作沿用 `--ef-secondary-*`：暗色页用浅灰胶囊，亮色页用深灰胶囊，文字与图标同步反转。
- 横带式独立页面顶部满宽细线：黄 50%／青 25%／品红 25%，复用 `--ef-band-stripe`。
- 选中反馈：金色外发光 + 信息遮罩；不再另外塞一个勾选框。多选集合与当前详情焦点是不同状态。
- 禁用才置灰，不能把能点击的“更多操作”做得像禁用。
- 反馈不要只靠颜色：搭配明确状态文字和必要图标。

## 3. 组件决策表：新增时直接选型

| 场景 | 使用 | 不使用 |
| --- | --- | --- |
| 保存、确认、取消、重试、打开目录等操作 | 共享胶囊按钮 | 页面自制矩形按钮、默认浏览器按钮 |
| 页面顶部工具栏、视图标签、书签标签 | 已有对应直角工具栏／标签组件 | 强制全部胶囊化 |
| 主题、语言及枚举设置 | 主题同款下拉触发器 + 共享 listbox | 原生蓝色选项表、自制第二套圆角菜单 |
| 开／关、精简／完整 | 左右滑动分段开关 | 两个互不关联的确认胶囊 |
| 缩放、数量、卡片尺寸 | `− 数值 +` 步进控件；有现成悬停／滚轮逻辑的沿用 | 三四个分散的小胶囊 |
| 行尾省略号、关闭、收藏等图标操作 | 对应图标控件 + 可访问名称 | 大图标挤满小圆、表情符号 |
| 多个常用文件夹 | 紧凑、可换行的小标签 | 每项占一整行的巨大胶囊 |

### 胶囊按钮结构

- 操作文字在**整颗按钮的几何中心**，不能按“文字 + 右侧图标”整组居中而偏右。
- 左侧短线、右侧动作图标、靠右等高线是装饰／语义层，不能挤占文字中心。
- 图标留足圆内空隙；不要给图标再叠一圈不必要的边框。
- 悬停／键盘焦点：按钮外出现细黄圈，不改变尺寸、不挤动邻居。
- 横带底部的大胶囊：按钮中心线与横带底线重合；后方扩大的胶囊基座与背景连为一体。
- 阴影在按钮下方，不给基座再套一圈阴影；不要用相同胶囊简单下移冒充扩大基座。
- 普通工具按钮不自动继承大号底部按钮尺寸。优先复用现有尺寸，不反复加 CSS 覆盖。

### 下拉框（包括语言）

- 选择框保持胶囊；展开时下半部灰色托底与菜单连体，箭头翻为白色向上；主题与语言必须同款，不得另留一条空隙。托底置于胶囊后面，不盖住胶囊圆角。
- 按实际屏幕坐标定位；支持界面缩放、窗口缩放、窄屏及弹窗入场运动，不能只测 100%。
- 当前项加深、白色标记；悬停位置加深。可滚动时保留清晰的继续滚动提示。
- 支持方向键、Home/End、Enter、Escape、焦点返回、外部点击关闭。
- 保存成功才提交语言状态；失败回退原值并提示。菜单不得被弹窗或背景遮住。

## 4. 页面与卡片

- 独立设置页（字体、白名单、卡片外观等）采用共同横带结构、三色线、左右等高线、居中底部操作。
- 有效内容区围绕鼠标常用的中央区域扩展，不是盲目拉到屏幕最左最右。宽屏增大可用空间，不拉长鼠标行程。
- 长列表只在内容区纵向滚动；窄窗口禁止整页横向滚动。需要时换行、重排或折叠。
- 长模型名在紧凑位置省略；不能把右侧栏撑成逐字换行长柱。完整名称可通过详情取得，不在图片悬停叠第二层名字提示。
- 图片悬停默认只显示鼠标右下方缩略图，避免原生 title、模型名气泡与缩略图重叠。
- 卡片外观外壳要完整显示；有框无框保持一致占位和收藏位置。方格／瀑布流共用尺寸调节习惯。
- 模型底光是卡片内部柔和渐变，按底模／文件夹规则区分，可自定义颜色和浓度；不遮文字，不做从下往上冲的波。
- 选中外金光向四周自然扩散，无硬分界。右侧“更多操作”展开状态按已有共用规则处理。
- 弹窗打开与关闭都要有动画；图片大图层必须高于模型信息层。关闭不能留下透明遮挡层。

## 5. 导航、背景与动效

- 导航激活项白底始终置顶；黄色从左向右推进，完成时打开右侧 `]`；右下清晰 `CFT + 箭头`。
- CFT 与符号一起短促乱码跳变；在黄色吃完黑色、右侧括号尚未完成时收束，避免拖到页面入场之后。
- 斜线纹理运动但不抢眼；动效优先 transform/opacity，不能造成布局抖动或圆角前沿闪帧。
- 普通背景沿用七星等高线地图与页面锚点；工作流 3D 沙盘用独立建筑场景，2D 节点画布用格子背景。
- 工作流卡片的等高线靠右、静止、独立，不把整个透视地图裁一块塞进去。
- 下载进度按实际比例从右向左扩散：0% 无光，100% 全蓝；暂停绿色，错误／等待重试红色。
- 完成顺序：全蓝 → 金光 → 居中打勾 → 行右移消失 → 自动进入日期／批次历史。非下载动画不能假装进度。
- 性能统一走 `CFTMotion` 与已有四档偏好：后台限帧、隐藏暂停、减少动态效果及拖窗策略，不新增各自永远运行的计时器。

## 6. 图标与字体

- 优先复用既有 SVG 图标库；直角工业感、明确轮廓、足够力量感。统一 viewBox、占位和视觉粗细，不用 emoji 代替。
- 检查更新使用已选定的 **A：直角循环**；不要重新换成圆形刷新。模型有新版也用同套无底色实心循环角标，放在收藏下方，不用警告三角／方框。
- 纯翻译不得修改原有按钮图标或布局；图标映射依据动作 ID，不依据译文推断。
- 关闭 X 在控件几何中心；侧栏预览图标与小号操作图标不能直接用同一尺寸硬塞。
- 中文沿用现有鸿蒙黑体；默认英文／拉丁字母采用用户指定 LINE Seed Sans Bold 1.002。
- LINE 文件只有 Bold，不伪称含 Regular/Medium；数字及用户已自定义字库遵循现有路由，不覆盖系统字体。
- 版权和许可只记录实际采用的字体；不得重新加入未发布的 URBANISM／城市化。
- 完整字体来源见 `FONT-NOTICES.md`。

## 7. 语言体系：功能语言与风格分开

目标 locale：`zh-CN`、`zh-TW`、`en`、`ja`、`ko`、`de`、`fr`、`es`、`pt-BR`、`ru`。

- 每个操作只有一个稳定的语义 key，例如 `models.selection.clear`，不得用中文原文作 key。
- 同一含义跨页复用；“清除选择”和“删除文件”、“移除记录”和“删除文件”必须分开。
- 新增按钮一次配齐标签、提示、禁用原因、成功／失败消息、确认文案和 aria-label 的词条。
- 文案不依赖图标猜测。标签用短动词，解释放说明／提示；破坏性操作必须说明作用对象和后果。
- 参数用命名占位符，例如 `{count}`、`{name}`，不要拼接半句中文。支持各语言复数、数字与日期格式。
- 切换语言应立即更新当前已打开页面及动态弹窗，不只改导航；不能丢失输入、选中状态、滚动位置和未保存设置。
- 不翻译模型名、触发词、作者原文、路径、用户输入、API 原始错误；需要解释时另加本地化说明。
- 禁止全局扫描 DOM 做繁简替换。台湾文案是独立本地化，不是字符转换；其他语言也不套中文语序。
- 缺词回退只作开发容错，不能以“有语言下拉框”宣称完整语言包已完成。
- 尚未配齐的语言必须标示预览／不完整；正式发布需先完成承诺范围的全部词条与验收。

### 简体／台湾繁体统一用词

| 含义 | 简体中文 | 繁體中文（台灣） |
| --- | --- | --- |
| Settings | 设置 | 設定 |
| File / Folder | 文件／文件夹 | 檔案／資料夾 |
| Save / Cancel | 保存／取消 | 儲存／取消 |
| Batch download | 批量下载 | 批次下載 |
| Model lookup | 反向解析 | 模型反查 |
| Workflow analysis | 工作流分析 | 工作流程分析 |
| Check for updates | 检查更新 | 檢查更新 |
| Start / Resume | 开始／继续 | 開始／繼續 |
| Pause / Retry | 暂停／重试 | 暫停／重試 |
| Select all / Invert | 全选／反选 | 全選／反向選取 |
| Clear selection | 清除选择 | 取消選取 |
| Remove record | 移除记录 | 移除紀錄 |
| Delete file | 删除文件 | 刪除檔案 |
| Copy / Paste | 复制／粘贴 | 複製／貼上 |
| Thumbnail / Cover | 缩略图／封面 | 縮圖／封面 |
| Preview | 预览 | 預覽 |
| Default | 默认 | 預設 |
| Mouse / Scroll wheel | 鼠标／滚轮 | 滑鼠／滾輪 |
| Skip onboarding | 跳过引导，直接使用 | 略過導覽，開始使用 |

- 英语：简短、自然的操作动词，避免冗长中式直译。
- 日语／韩语：采用当地软件常用词和一致礼貌程度，不逐字翻译中文。
- 德／法／西／葡（巴西）／俄语：为较长文本预留空间，处理复数，不用强制缩小字号解决布局。
- 日期／数量使用相应 locale；版本号、API Key、JSON、ComfyUI 等产品／技术名称不擅自改写。
- 「明日方舟味」是独立可选文案风格，不是一个国家语言，不替换标准功能名称，不让删除／覆盖等风险提示变晦涩。先出小样审批，再制作。

## 8. 新增按钮的固定流程

1. 明确动作、对象、主次、启用条件、成功／失败和破坏性影响。
2. 从第 3 节选现成组件；保留原生 button/select 语义与真实事件处理。
3. 注册稳定图标映射，不依靠中文文字猜图标；语言变化后图标不得改变。
4. 在词条目录加语义 key 与十种语言；不能完成时明确列为未完成，不能默默回退当交付。
5. 接入现有主题、缩放、焦点、动效和性能机制；不要复制一套弹窗／按钮 CSS。
6. 验证亮暗、窄窗口、长语言、鼠标和键盘；截图检查再报告。

## 9. 最低验收矩阵

- 两主题；界面缩放 80%／100%／125%／150%；窄窗口和宽屏。
- 下拉框首次打开、切换后再打开、贴近底边、入场动画期间打开：不得叠圆角、越界、错位、被遮挡。
- 新手引导每一步、七页工具栏、设置分区、弹窗、右键和通知：不得以部分按钮翻译冒充整页翻译。
- 键盘焦点可见；Escape 关闭后返回触发器；图标按钮都有可访问名称。
- 选择／全选的范围符合当前筛选；更新、版本选择、省略号等真实可点击；装饰层 pointer-events 不拦截。
- 切换语言不翻译用户数据、不重复绑定事件；保存失败有回退；后台／最小化无多余持续动画。
- 检查编译／单测与截图／鼠标验收分开报告；未测项明确写出，不宣称全部完成。
