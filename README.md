# CivitaiFreeTool

> Civitai / HuggingFace 模型下载与管理一站式工具 —— 免费 · 全功能 · 无付费墙

CivitaiFreeTool 是一款桌面端（Windows）的 AI 模型下载与管理工具：批量下载 C 站 / HuggingFace 模型，自动识别 Early Access（付费期），到期自动提醒；内置完整的模型管理（缩略图、校验、重命名、整理分类、生成 SD json、翻译、反向解析、工作流分析）。所有功能免费使用。

## ⬇️ 批量下载（Civitai / HuggingFace）

- **多链接解析**：一次性粘贴多行 C 站模型链接，自动拆行逐个解析；支持 `civitai.red` / `civitai.com` / `huggingface.co`
- **📋 剪贴板一键粘贴**：点「粘贴剪贴板链接」自动读取剪贴板，`http` 开头的链接全部自动填入（一行一条）
- **多版本挑选**：解析模型后自动挑主文件，文件名 = 模型名 + 版本号，避免同名覆盖
- **图片页下载**：粘贴 C 站图片页链接，自动递归提取图中引用的所有模型（已存在同名文件自动跳过）
- **付费（Early Access）识别**：解析到付费期模型时弹窗选择——
  - ⏰ 加入待办（自动按 C 站免费到期时间计算提醒）
  - 💳 仍要下载（强制入队）
  - 🌐 浏览器打开
- **下载受限自动处理**：下载被 C 站拦截时立即识别并弹窗：花费积分/重试下载 · 加入待办并移除 · 浏览器打开
- **解析完成自动跳转**下载管理页查看进度
- **下载能力**：
  - 断点续传（`.part` 临时文件 + `Range` 头），中断后可继续
  - 下载后 SHA256 完整性校验（C 站 CDN 哈希不一致时保留文件而非误删）
  - 并发下载数可调、实时速度/进度显示
  - 支持代理、API Key（Bearer）认证、下载超时设置
  - 任务持久化：重启软件自动恢复未完成任务

### HuggingFace

- 粘贴仓库 / tree 链接，递归列出全部文件（按大小倒序）
- 弹窗勾选下载（默认勾选模型扩展名），支持全选/全不选
- **保留仓库相对子目录结构**下载到本地

## ⏰ 待办下载清单

- 记录 Early Access / 付费模型，显示剩余天数
- **到期后打开软件自动弹窗提醒**，一键把链接回填到下载页
- 到期时间自动选择：优先取 C 站 `earlyAccessDeadline`，无则默认 7 天
- 支持删除条目、手动加入

## 📂 模型管理（核心）

### 扫描与展示

- 递归扫描模型目录，支持 `.safetensors .ckpt .pt .pth .bin .gguf .onnx`
- **列表 / 瀑布流**两种视图切换（**默认视图可在设置里指定**）；缩略图分批懒加载（不卡界面）
- 12 列信息：勾选、缩略图、文件名、C 站模型名、类型、基础模型、版本、更新状态、哈希、大小、下载时间、路径
- 点击表头排序；**列宽拖拽且记忆**；**表头右键 = 列显隐菜单**
- 筛选（文件名 / C 站名 / 路径）、全选、清除、反选、勾选计数
- **文件夹显示**：树形面板逐目录切换显示/隐藏（用不上的文件夹可隐藏）

### 整理模型（三模式）

- **手动**：逐个弹窗选择目标文件夹移动
- **C 站 tags 自动分类**：`<类型目录>/<基础模型>/<tags 分类>` 两级目录——如 `Lora/光辉/Style`；按环境映射目录（WebUI：Lora、Stable-diffusion、VAE、embeddings；ComfyUI：loras、checkpoints、vae）；15 类 tags（Style/Pose/Character/Anime/Clothing/Concept/Backgrounds…）自动映射；**无 tags 的模型保持原位**，未知类型目录一律不动；带守卫（已在目标目录/同名不重复移动）
- **自定义规则**：`关键词1,关键词2 -> 文件夹` 关键词规则整理
- 所有移动操作写入 `organize_log.json`，可用「恢复误整理」一键回退

### 详情面板（双击打开）

- C 站风格二级界面：封面画廊（本地 images 目录 + 在线图）、作者徽章、类型/基础/版本/NSFW 徽章
- **🎯 触发词多套独立展示**：每套一行（带序号 ①②③…），与 C 站展示一致；**点击任意一套单独复制该套**（非整组复制）
- **编辑信息**：模型名/触发词（多行，每行一套）/类型/基础模型/版本/简介，同步写入 `.civitai.info` 与 `.json`
- 📤 **自定义封面**：上传本地图片压缩覆盖为 `preview.png`
- 🌐 打开 C 站 / ✏️ 重命名 / 📤 发送到反向解析 / 🌏 翻译简介 / 🀄 汉化文件名
- 🖼️ **下载全部图片**到 `<名>.images/` 目录（带进度）
- 📄 生成 SD json
- **详情图片右键**：复制图片（优先复制图片数据）/ 打开所在文件夹 / 复制提示词 / 打开原图网站

## 🔄 反向解析

- **输入**：添加文件（模型扩展名过滤）或添加文件夹（递归扫描），也可从模型管理一键发送
- **能力**：多线程 SHA256 → C 站 `/model-versions/by-hash` 反查 → 生成 `<名>.info.json`（C 站格式，含 stats/trainedWords/images/files）
- 可选自动翻译简介（`auto_translate` 配置）
- 表格显示文件 / SHA256 前缀 / 状态（等待/反查中/成功/未收录/失败/已取消）/ 模型名/版本
- 支持暂停/继续/停止、移除选中、清空、筛选

## 🧩 工作流分析

- 拖入或选择 **.json**（UI 格式 / API prompt 格式）、**.png / .webp**（内嵌 workflow 数据）
- 输出：节点列表（类型/标题/widgets）、**引用的模型**（按文件名 + SHA256 前缀与本地模型库匹配）、本地未命中的模型提供「🔍 搜索下载」跳转 C 站搜索、正/负向提示词提取

## 📦 安装

- **Windows 10/11**，下载 `CivitaiFreeToolWeb.exe`（约 34MB）直接运行，无需安装
- 首次运行依赖 WebView2 运行时（Win11 自带；Win10 一般已装，缺失时 Windows 会提示安装）
- 配置保存在程序同目录 `user_config.json`（**含 API Key，请勿分享该文件**）

## 🗝️ 获取 Civitai API Key

1. 打开 https://civitai.com/user/account 并登录（Account Settings → API Keys）
2. 点击「New API Key」生成并复制
3. 粘贴到软件设置页或首次引导
