# CivitaiFreeTool 一键添加（Chrome 扩展）

在浏览器里浏览 Civitai 模型页时，点击扩展图标即可把当前页面**一键添加到 CivitaiFreeTool 的批量下载列表**，回到软件点「解析」即可下载。

## 原理
- CivitaiFreeTool（v2.1.0+）内置一个仅本机可访问的桥服务 `127.0.0.1:47531`；
- 扩展点击图标 → 校验当前页是 Civitai 模型页 → 发送到桥服务；
- 软件前端批量下载页每 3 秒检查一次，新链接自动出现在 URL 行（提示「🌐 已从浏览器添加 N 条链接」）；
- 链接存于软件目录 `browser_queue.json`，即使软件当时没开批量下载页也不会丢。

## 安装
1. 打开 Chrome，地址栏进入 `chrome://extensions/`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本文件夹（`chrome-extension`）
4. 工具栏出现图标（可右键图标 → 固定）

## 使用
1. **先打开 CivitaiFreeTool.exe**（桥服务随软件启动）
2. 在 Chrome 打开 Civitai 模型页（`civitai.red/models/...` 或 `civitai.com/models/...`）
3. 点击扩展图标 → 图标角标显示绿色 ✓（已在队列则显示 =）
4. 回到软件「批量下载」页，链接已自动加入，点「解析」开始下载

也可以**右键页面或链接** → 「添加到 CivitaiFreeTool」。

## 常见问题
| 现象 | 原因与处理 |
|---|---|
| 角标显示红色 ! 且提示「无法连接」 | CivitaiFreeTool 未运行 → 先打开软件 |
| 角标显示红色 ! 且提示「不是模型页」 | 当前页不是 Civitai 模型页（图片页/主页等不支持） |
| 点击无反应 | 扩展未加载成功，检查 chrome://extensions 是否已启用 |
| 软件里没出现链接 | 确认软件版本 ≥ v2.1.0，且停留在「批量下载」页（轮询仅在该页进行；切回页面时会立即拉取一次） |

## 说明
- 仅接受 `civitai.red` / `civitai.com` 的模型页（含 `?modelVersionId=` 版本链接和 `/api/download/models/` 下载链接）；
- 重复添加自动去重；
- 桥服务只监听 `127.0.0.1`，且仅响应 Chrome 扩展与本机页面来源，其他网站无法向你的队列写入。
