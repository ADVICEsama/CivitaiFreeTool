# CivitaiFreeTool 扩展 1.3.1 · Chrome / Edge

## 安装 / 更新
解压后打开 chrome://extensions，启用开发者模式，加载已解压目录。更新原目录后点击“重新加载”。

## 界面外观
弹窗采用终末地风格，亮暗配色跟随系统；更新外观后请在扩展管理页重新加载。功能和权限不变。

## 发送当前页
先打开 CFT（推荐 v2.6.25）并在设置填写保存 Civitai API Key。点击扩展图标，在“当前页面”确认模型标题与链接，点“发送当前页到 CFT”。多文件选择在软件内完成。

## 批量标签页
1. 打开想下载的多个 C 站模型详情页，无需逐页点击扩展。
2. 打开扩展 → “批量标签页”。默认列出全部浏览器窗口的模型页，也可切换“当前窗口”。即使当前页不是 C 站，也能使用此入口。
3. 初始全选；可搜索、取消不需要的页，或用全选按钮选择当前搜索结果。
4. 点“发送选中 N 项到 CFT”。关闭小窗不打断后台提交；重新打开可查看结果。不会关闭或切换你的标签页。
5. 在 CFT 下载管理查看解析、文件选择与进度。扩展“已提交”只表示软件接收链接，不等于已下载完成。

同模型同版本同文件 ID 的 red/com 重复页合并；不同版本 / 文件保留。一次最多 500 个不同条目。
未收到确认的条目会显示“待核对”，不会自动重发。先查看 CFT；如确需再次发送，点“清除提交记录（允许重新发送）”，此操作只清扩展记录，不删除 CFT 任务。

右键模型页或模型链接 → “发送到 CivitaiFreeTool”仍可使用。

## 隐私和权限
仅在主动打开扩展时读取标签页标题与链接，不注入网页。过滤非 C 站模型 URL，移除链接里的 token / 追踪参数；仅向 127.0.0.1:47531 发送用户选择的模型 URL，不传 Cookie、网页内容或 API Key。storage 权限用于保存上一批的提交结果与重复发送保护。
只获取此浏览器可访问的标签，不能跨 Chrome / Firefox 枚举；隐私窗口须在浏览器中明确允许扩展访问。
